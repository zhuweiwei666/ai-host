# 🌟 沉浸式 AI 伴侣交互系统

## 愿景：颠覆气泡式聊天

传统聊天 App 的问题：
- 冰冷的气泡列表，像读短信
- 头像只是一个静态小圆圈
- 语音是"附加功能"
- 用户感觉在"操作 App"，而不是"和人交流"

**我们的目标**：创造一种前所未有的交互体验——
> 用户打开 App，不是在"看聊天记录"，而是"面对一个活生生的人在和你说话"。

## 🎨 视觉设计原则

### ❌ 不要这样（传统）

```
┌──────────────────────────────┐
│ [👤] 今天好累啊              │  ← 用户气泡
│                              │
│        [😊] 抱抱你，累了... │  ← AI 气泡
│                              │
│ [👤] 谢谢                    │  ← 又一个气泡
│                              │
│        [😊] 不客气~          │  ← 堆叠、冰冷
└──────────────────────────────┘
```

### ✅ 要这样（沉浸式）

```
┌──────────────────────────────────────────┐
│                                          │
│         ┌────────────────────┐           │
│         │                    │           │
│         │   [3D 活体角色]    │           │
│         │   温柔地看着你     │           │
│         │   嘴唇在动...      │           │
│         │                    │           │
│         └────────────────────┘           │
│                                          │
│      "抱抱你，累了就靠在我肩上..."       │  ← 字幕式文字
│                                          │
│  ─────────────────────────────────────── │
│  │ 说点什么...                    🎤 │  │  ← 简洁输入框
│  ─────────────────────────────────────── │
│                                          │
└──────────────────────────────────────────┘
```

### 核心差异

| 维度 | 传统气泡 | 沉浸式 |
|------|---------|--------|
| **视觉焦点** | 文字列表 | 3D 角色 |
| **角色存在感** | 小头像装饰 | 占据 60%+ 画面 |
| **文字呈现** | 永久堆叠的气泡 | 像字幕一样浮现、消失 |
| **语音** | 可选附加 | 主要输出方式 |
| **情感传递** | 靠 emoji 表情 | 角色表情+语调+姿态 |
| **用户感受** | 在读消息 | 在和人对话 |

## 🔧 技术实现要点

### 1. 3D 角色渲染

已有基础：Spatial Avatar（深度图+法线图+Metal 着色器）

**需要扩展**：
- 嘴型同步（Lip Sync）：分析 TTS 音频的音素，驱动嘴部形变
- 表情系统：定义 6-8 种基础表情，可混合插值
- 姿态动画：点头、前倾、侧头等微姿态

```swift
enum Emotion: String {
    case neutral, happy, caring, shy, excited, sad, thinking, flirty
}

struct CharacterState {
    var emotion: Emotion
    var intensity: Float      // 0-1
    var isSpeaking: Bool
    var currentViseme: Viseme // 当前音素对应的嘴型
    var headTilt: Float       // 头部倾斜
    var lookAtUser: Bool      // 是否注视用户
}
```

### 2. TTS 同步系统

后端已有：Fish Audio TTS

**iOS 需要**：
- 预加载/流式播放 TTS 音频
- 音频分析提取音素（可用 `AVAudioEngine` + 预处理）
- 字幕逐字显示与音频同步

```swift
class SpeechController {
    func play(text: String, audioUrl: URL) {
        // 1. 开始播放音频
        audioPlayer.play(audioUrl)
        
        // 2. 同步显示字幕
        subtitleView.animateText(text, duration: audioDuration)
        
        // 3. 驱动角色嘴型
        lipSyncEngine.start(audioUrl)
    }
}
```

### 3. 字幕系统（非气泡）

```swift
class SubtitleView: UIView {
    func animateText(_ text: String, duration: TimeInterval) {
        // 逐字淡入显示
        for (i, char) in text.enumerated() {
            let delay = duration * Double(i) / Double(text.count)
            animateCharacter(char, delay: delay)
        }
        
        // 播完后整体淡出
        DispatchQueue.main.asyncAfter(deadline: .now() + duration + 1.5) {
            self.fadeOut()
        }
    }
}
```

### 4. 历史记录（可选查看）

虽然主界面不显示气泡堆叠，但用户可能需要回看：

```
主界面：沉浸式（角色 + 字幕 + 语音）
        │
        ├─ 上滑/点击按钮 → 展开历史记录（传统列表模式）
        │
        ▼
┌─────────────────────────────┐
│  历史记录（可折叠）          │
│  - 今天 14:30               │
│    你：今天好累啊            │
│    她：抱抱你...             │
│  - 今天 10:15               │
│    ...                       │
└─────────────────────────────┘
```

## 🎯 API 设计建议

### Chat 接口扩展

```http
POST /api/chat
```

**Request**：
```json
{
  "agentId": "xxx",
  "message": "今天好累啊",
  "requestTTS": true,          // 请求语音
  "requestEmotion": true       // 请求情感分析
}
```

**Response**：
```json
{
  "message": {
    "content": "抱抱你，累了就靠在我肩上休息一下吧",
    "audioUrl": "https://.../tts_xxx.mp3",
    "audioDuration": 3.5,      // 秒
    "emotion": {
      "primary": "caring",
      "intensity": 0.8,
      "secondary": "gentle"
    },
    "visemes": [               // 可选：预计算的音素时间轴
      { "time": 0.0, "viseme": "silence" },
      { "time": 0.1, "viseme": "AA" },
      { "time": 0.3, "viseme": "B_M_P" },
      ...
    ]
  }
}
```

> 把"聊天界面"变成"和真人视频通话的感觉"——
